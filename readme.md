# 💎 Souvenir (수베니아) - 주얼리 쇼핑몰

> **"소중한 순간을 영원히 기억하는 방법"**  
> 화이트 & 블랙 톤의 모던하고 미니멀한 감성을 담은 주얼리 쇼핑몰입니다.  
> 본 프로젝트는 별도의 백엔드 서버 없이 **순수 Front-end 기술(HTML, CSS, Vanilla JS)**과 **JSON 데이터 연동**만으로 구현된 정적 웹사이트입니다.

---

## 🛠️ 개발 스펙 (Tech Stack)
- **Frontend**: HTML5, CSS3, JavaScript (Vanilla JS / ES6+)
- **Data Management**: Local JSON File (`products.json`)
- **Deployment**: GitHub Pages (정적 웹사이트 호스팅 예정)

## 🚫 제외된 기능 (Scope Limitation)
- 본 사이트는 UI/UX 구현 및 동적 상품 화면 렌더링에 집중한 프로젝트입니다.
- **로그인, 회원가입, 결제 시스템 등 서버 및 데이터베이스 연동이 필요한 백엔드 기능은 포함하지 않습니다.**

## 🎨 UI/UX & Design Concept

수베니아는 '기념일을 기억하는 주얼리'라는 아이덴티티를 시각적으로 전달하기 위해 **고급스러움, 절제미, 직관성**을 핵심 키워드로 디자인되었습니다.

### 1. 모던 앤 미니멀 비주얼
- **Color Palette**: `#FFFFFF`(화이트)와 `#000000`(블랙)의 대비를 극대화하여 정갈한 세련미를 연출하고, 주요 가이드라인 및 포인트 요소에 **골드(Gold)** 컬러를 매칭하여 고급스러운 감성을 한층 더합니다.
- **Typography**: 얇고 정교한 Serif 계열과 깔끔한 Sans-serif 폰트를 조화롭게 매칭하여 고급스러운 감성을 전달합니다.
- **Grid System & Whitespace**: 상품 간의 여백을 과감하고 충분하게 확보하여 시각적 피로도를 낮추고, 3~5열의 반응형 그리드 배열을 통해 화면 크기에 상관없이 갤러리에 온 듯한 레이아웃을 유지합니다.
- **Whitespace (여백의 미)**: 상품 간의 충분한 여백을 확보하여 시각적 피로도를 낮추고 갤러리에 온 듯한 레이아웃을 구현합니다.
- **비주얼 영역 (Hero Section)**: 메인 페이지 상단에 브랜드 아이덴티티를 매력적으로 보여줄 수 있는 대형 배너 이미지를 배치하여 첫인상에서 깊은 몰입감을 전달합니다.
- **브랜드 스토리 및 소셜 영역**: 메인 배너 하단의 브랜드 아이덴티티 소개 섹션, 푸터 직전의 인스타그램 피드 레이아웃(@INSTAGRAM)을 통해 감성적인 브랜드 브랜딩을 강화합니다.

### 2. 고정형 네비게이션 (Sticky GNB)
- **상단 고정 레이아웃**: 메인 메뉴(악세사리, 기념일, 별자리, 베이비)는 항상 화면 상단에 고정되어 존재합니다. 사용자가 어떤 페이지 영역에 있더라도 언제든지 다른 카테고리로 즉시 이동할 수 있도록 직관적인 동선을 제공합니다.
- **데스크톱 레이아웃**: 상단 헤더 좌측에 브랜드 로고, 우측에 4대 메인 메뉴를 배치하여 균형감 있고 직관적인 내비게이션을 제공합니다.
- **반응형 모바일 UI**: 모바일 및 태블릿 환경에서는 메인 메뉴가 햄버거 버튼(Toggle Menu)으로 전환되며, 버튼 클릭 시 숨겨진 메뉴 리스트가 부드럽게 나타나도록 UI를 최적화합니다.

### 3. 동적 화면 재구성 (Dynamic Page Restructuring)
- 메인 메뉴를 클릭하면 페이지가 완전히 새로고침되는 대신, **상단 메뉴만 남겨둔 채 하단의 콘텐츠 영역(Hero 배너, 타이틀, 상품 그리드 등)이 해당 카테고리의 콘셉트에 맞춰 완전히 새로운 화면으로 재구성**됩니다.
- **Micro Interactions**: 카테고리 전환 시 상품 리스트와 배너가 부드럽게 스며들듯 나타나는 `Fade-in` 애니메이션 효과를 적용하여 자연스러운 내비게이션 경험을 제공합니다.
- *예시 (기념일 메뉴 클릭 시)*: 메인 배너가 '웨딩/커플 전용 감성 배너'로 교체되며, 하단에는 기념일 카테고리에 특화된 레이아웃과 상품 리스트가 스며들듯(Fade-in) 나타납니다.

## ✨ 핵심 구현 기능 (Key Features)

### 1. 4대 메인 네비게이션 및 서브 콘텐츠
- **악세사리 (Accessories)**: 일반 주얼리 상품 리스트 (반지, 목걸이, 귀걸이 등 기본 그리드)
- **기념일 (Anniversary)**: 수베니아만의 시그니처 서비스 (웨딩 반지, 커플링 등 로맨틱한 무드의 배너와 레이아웃)
- **별자리 (Zodiac)**: 12가지 별자리 테마를 모티브로 한 신비로운 무드의 맞춤형 디자인 영역
- **베이비 (Baby)**: 소중한 아이를 위한 돌반지 및 백일 기념 주얼리에 맞춘 따뜻하고 정갈한 톤앤매너

### 2. 비동기 데이터 렌더링 및 상태 관리 (JSON Fetch API)
- 상품의 이미지, 이름, 가격, 카테고리 정보 등을 `data/products.json`에서 분리하여 관리합니다.
- JavaScript로 상단 메뉴의 클릭 이벤트를 감지하여, 선택된 카테고리에 맞는 **배너 이미지 경로, 텍스트, 그리고 필터링된 상품 데이터**를 비동기적으로 불러와 화면을 다이내믹하게 실시간 마운트합니다.
